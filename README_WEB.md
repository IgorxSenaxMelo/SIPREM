# SiPREM — versão web

Veja o `README.md` para instalação, formato das planilhas e descrição das telas.

Resumo das abas:

1. **Ranking**: tabela com busca/filtros, explicação por requisito e downloads (Excel, HTML, CSV).
2. **Gráficos**: pesos FAHP, mapas de posições/classes/PROMETHEE I por faixa de requisitos, GAIA.
3. **Especialistas**: aderência ao grupo, histogramas de diferenças, Kappa e Spearman.
4. **Entradas**: abas usadas/ignoradas, pesos e configuração.
